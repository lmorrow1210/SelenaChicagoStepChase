# One Step Ahead
### The Search for Selena Chicago

*"She's always one step ahead."*

A high-stakes, competitive, weekly social fitness game built on the Google
Health API (Fitbit/wearables). Join **The Loop Bureau** and hunt Selena
Chicago — an elite, brilliant independent spy mastermind — across real-world
United States geography. Every Sunday night the board resets as she vanishes
into a new city silhouette.

See /docs for full product spec and design system brief.
